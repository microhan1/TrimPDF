TrimPDF v1.0.5 · Windows

TrimPDF 사용 설명서

PDF를 창에 끌어다 놓으면 페이지마다 위·아래·왼쪽·오른쪽 여백을 찾아 잘라내고, 내용을 페이지에 맞게 키워서 새 파일로 저장합니다. 스캔한 책이나 여백이 넓은 문서를 태블릿·이북리더에서 크게 볼 때 유용합니다.

원본은 그대로결과는 같은 폴더에 _TrimPDF를 붙인 새 파일로 저장됩니다. 같은 이름이 이미 있으면 덮어쓰지 않고 (2)처럼 번호를 붙입니다.
글자는 선명하게이미지로 바꾸지 않아 텍스트 선택·검색과 목차가 유지됩니다.
내 PC에서만 처리인터넷에 파일을 올리지 않고, 쪽수 제한도 없습니다.

시작하기

설치 과정은 없습니다. TrimPDF.exe 파일 하나만 있으면 Windows 10·11에서 바로 실행됩니다. Python 같은 다른 프로그램도 필요 없습니다.

GitHub Releases에서 최신 TrimPDF.exe를 받을 수 있습니다.

  1. 원하는 폴더에 exe를 둡니다바탕화면이나 문서 폴더 어디든 괜찮습니다. 자주 쓴다면 바탕화면에 바로 가기를 만들어 두세요.
  2. 더블클릭해서 실행합니다실행할 때마다 준비하느라 창이 뜨기까지 몇 초 걸립니다.
  3. PDF를 창에 끌어다 놓습니다처리가 끝나면 아래 「처리 결과」에 ✓ 파일명_TrimPDF.pdf가 표시됩니다.
“Windows의 PC 보호” 창이 뜨면
인증서로 서명되지 않은 개인 제작 프로그램이라 처음 실행할 때 나타날 수 있습니다. 추가 정보를 누른 뒤 실행을 누르세요. 백신이 검사를 위해 잠시 막는 경우도 있습니다.

알아둘 점

  • 원본 파일은 전혀 바뀌지 않습니다.
  • 처리하기 전에 진행 표시줄 오른쪽의 「미리보기…」를 누르면, 쪽마다 어디가 잘리는지 빨간 상자로 볼 수 있습니다. 흐리게 덮인 곳이 잘려 나갑니다. 마음에 들면 「이 설정으로 처리」를 누르세요.
  • 처리 중에는 같은 자리가 「취소」로 바뀝니다. 취소하면 그 파일의 결과는 만들지 않고, 기다리던 파일도 처리하지 않습니다. 처리 중에 창을 닫으면 지금 파일을 마친 뒤 닫히고, 한 번 더 누르면 바로 닫힙니다.
  • 처리가 끝나면 결과 목록의 파일 이름을 눌러 바로 열 수 있고, 「폴더 열기」로 저장된 위치를 볼 수 있습니다.
  • 텍스트 선택·검색, 목차(책갈피)는 결과 파일에도 그대로 남습니다.
  • 원본의 링크, 메모·주석, 입력 양식은 결과 파일에 옮겨지지 않습니다.
  • 화면 언어는 오른쪽 위에서 한국어 · English · 中文 · 日本語 중에 고를 수 있고, 고른 언어는 %APPDATA%\TrimPDF에 저장되어 다음 실행에도 유지됩니다.
  • 처리 속도는 PC에 따라 다르지만, 300쪽 안팎의 스캔 책 한 권이 15초 정도 걸립니다.
  • 결과 파일 크기는 원본과 비슷합니다. 스캔 이미지를 다시 압축하지 않아 화질이 떨어지지 않습니다.
  • 회전된 페이지와 가로형 페이지도 방향을 유지한 채 처리합니다.
  • 실행할 때 새 버전이 있는지 확인하려고 도구 이름과 버전만 책갈피 서버(chaekgalpi.co.kr)에 보냅니다. 파일은 보내지 않고, 하루 한 번만 확인하며, 오른쪽 위 「새 버전 확인」 체크를 해제하면 끌 수 있습니다. 새 버전이 있으면 창 아래쪽에 한 줄 안내가 나오고, 「업데이트」를 누르면 책갈피 툴 페이지가 열립니다. 새 버전을 자동으로 내려받거나 바꾸지 않습니다.

동작 원리

궁금한 분을 위한 짧은 설명입니다.

  1. 페이지를 그려서 내용 영역을 찾습니다페이지마다 종이 배경의 밝기를 재고, 배경보다 확실히 어두운 부분을 약 1mm 크기의 칸 단위로 찾습니다. 흩어진 먼지 같은 점과 가장자리에 붙은 얇은 스캔 그림자는 무시합니다.
  2. 결과 페이지 크기를 정합니다확대 배율 한도와 좌우 빈 공간 비율을 반영해 크기를 계산하고, 크기 통일이 켜져 있으면 전체 페이지의 대표 크기(중앙값)로 맞춥니다.
  3. 원본 페이지를 잘라 새 페이지에 배치합니다내용 영역만 새 페이지 가운데에 비율을 유지해 놓습니다. 원본을 이미지로 바꾸지 않고 PDF 내용을 그대로 옮기므로 글자가 선명합니다.

TrimPDF User Guide

Drop a PDF onto the window and TrimPDF finds the top, bottom, left and right margins of every page, trims them, and enlarges the content to fit the page before saving a new file. It's handy for reading scanned books or wide-margin documents at a comfortable size on tablets and e-readers.

Your original stays untouchedThe result is saved next to it as a new file ending in _TrimPDF. An existing file is never overwritten; a number such as (2) is added instead.
Text stays sharpPages aren't turned into images, so text selection, search and bookmarks keep working.
Everything stays on your PCFiles are never uploaded, and there's no page limit.

Getting started

There's nothing to install. TrimPDF.exe is a single file that runs on Windows 10 and 11 without Python or anything else.

Download the latest TrimPDF.exe from GitHub Releases.

  1. Put the exe in any folderYour desktop or Documents folder is fine. If you use it often, create a desktop shortcut.
  2. Double-click to run itThe window takes a few seconds to appear each time while it gets ready.
  3. Drop a PDF onto the windowWhen it's done, ✓ filename_TrimPDF.pdf appears under “Results”.
If “Windows protected your PC” appears
This can show up the first time because TrimPDF is a personal project without a code-signing certificate. Click More info, then Run anyway. Antivirus software may also hold it briefly for a scan.

Adding files

Use whichever of these three ways you like. Drop several files at once and they're processed one after another.

Drop onto the windowDrop PDFs onto the dashed box at the top of the window. This is the usual way.
Drop onto the exe iconWith TrimPDF closed, drop PDFs onto TrimPDF.exe or its shortcut. The window opens and starts processing right away.
Click to browseClick the dashed box to open a file picker.

Results are saved in the same folder as the original.

meeting_notes.pdf→meeting_notes_TrimPDF.pdf
Options are read at the moment you add a file. If you change a setting, add the file again to apply it. An existing _TrimPDF.pdf with the same name is overwritten.

Troubleshooting

Some pages still have margins
The app took scan smudges, shadows or a pale background colour for content. Lower “White level” to about 200 and process the file again.
Faint text or page numbers sit too close to the edge
Raise “Margin to keep” to 10 pt or more.
A page with a single picture is too big or too small
“Max zoom” was applied to that page. Raise the value to enlarge it more, or lower it to enlarge it less.
There is still space on the left and right
The text area is taller and narrower than the page. Set “Side space” to 0 to fit the page width to the content.
A white strip appears next to a full-colour page
That page has a different shape from the common page size. Turn off “Same size for all pages” if it bothers you.
Results show ✕ and nothing is saved
A _TrimPDF.pdf with the same name can't be overwritten while it's open in a PDF viewer. Close the viewer and add the file again. If it says “Password-protected PDFs can't be processed”, remove the password first.
It says “Skipped (not a PDF)”
Only files ending in .pdf are processed, and dropping a whole folder shows this too. Select the PDF files themselves.

Good to know

  • Your original file is never changed.
  • Before processing, click “Preview…” to the right of the progress bar to see, page by page, what will be trimmed: the red box is kept and the shaded area is cut. Click “Process with these settings” when you are happy.
  • While processing, the same spot becomes “Cancel”. Cancelling makes no result for that file and skips the files still waiting. Closing the window while processing waits for the current file; close again to quit at once.
  • When a file is done, click its name in the results list to open it, or “Show in folder” to see where it was saved.
  • Text selection, search and bookmarks carry over to the result.
  • Links, comments and form fields from the original are not copied.
  • The interface language can be switched at the top right between 한국어, English, 中文 and 日本語. Your choice is saved in %APPDATA%\TrimPDF and kept for next time.
  • Speed depends on your PC; a scanned book of about 300 pages takes around 15 seconds.
  • The result is about the same size as the original. Scanned images aren't recompressed, so quality doesn't drop.
  • Rotated and landscape pages keep their orientation.
  • To see whether a newer version exists, TrimPDF sends only the tool name and its version to the Chaekgalpi server (chaekgalpi.co.kr) when it starts. Your files are never sent, the check runs at most once a day, and you can turn it off with the “Check for updates” checkbox at the top right. If a new version exists, a one-line notice appears at the bottom of the window and “Update” opens the Chaekgalpi tools page. TrimPDF never downloads or replaces itself.

How it works

A short explanation for the curious.

  1. It renders each page to find the contentIt measures the brightness of the paper and looks for areas clearly darker than it, in cells of about 1 mm. Scattered specks of dust and thin scan shadows along the edges are ignored.
  2. It decides the result page sizeThe size reflects the zoom limit and the side-space setting. With “Same size for all pages” on, every page gets the typical (median) size.
  3. It places the content on a new pageOnly the content area is placed, centred and at its original proportions. The PDF content is copied as-is rather than as an image, so text stays sharp.

TrimPDF 使用说明

把 PDF 拖到窗口里，TrimPDF 会逐页找出上下左右的边距并裁掉，再把内容放大到适合页面的大小，另存为新文件。适合在平板或电子阅读器上阅读扫描书籍或页边距很宽的文档。

原文件保持不变结果以加上 _TrimPDF 的新文件保存在同一文件夹。如已有同名文件，不会覆盖，而是加上 (2) 等编号。
文字依旧清晰不会把页面转成图片，文字选择、搜索和书签都能继续使用。
只在本机处理文件不会上传到网络，也没有页数限制。

快速开始

  2. 双击运行每次启动都需要几秒钟准备，窗口才会出现。
  3. 把 PDF 拖到窗口里处理完成后，下方“处理结果”中会显示 ✓ 文件名_TrimPDF.pdf。

选项详解

大多数文档使用默认值即可。如果结果不理想，只需微调相关选项。pt 是点，1 pt 约为 0.35 mm。在程序中把鼠标移到选项名称上也能看到说明。

选项默认值作用什么时候调整
处理方式
裁边并放大已选裁掉边距后把内容放大到适合页面，文字比例保持不变。大多数情况下选这个即可。
仅裁边（保持原大小）—只去掉边距、不放大，页面会缩小到内容大小。需要保持原始字号时，例如打印或粘贴到其他文档。
裁剪
保留边距5 pt在检测到的内容周围保留这么多空白。5 pt 约为 1.8 mm。文字太贴边时，调到 10 左右。
白色阈值235在 0（黑）到 255（白）之间，比该值暗的部分视为内容。扫描件会根据纸张底色自动收紧。如果污点或浅色底色导致边距裁不干净，降到 200 左右。
放大（仅“裁边并放大”时有效）
左右留白50 %内容又窄又长时，左右会出现空白。程序会缩小页面宽度，只保留这个比例的空白。0 表示去掉左右空白，100 表示保持原页面宽度。
最大倍数1.5 ×限制放大倍数，避免只有小图或几行字的页面被放得过大。想放得更大可调到 2.0，设为 0 表示不限制。
所有页面统一尺寸开启把所有页面调成相同尺寸，纵向和横向页面分别统一。希望每页都贴合各自内容时关闭。
界面
语言跟随 Windows用右上角的按钮选择 한국어、English、中文 或 日本語。首次启动时跟随 Windows 显示语言。想换一种界面语言时。

常见问题

有些页面的边距没有裁掉
程序把扫描污点、阴影或浅色底色当成了内容。把“白色阈值”降到 200 左右后重新处理。
浅色文字或页码离边缘太近
把“保留边距”调到 10 pt 以上。
只有一张图的页面太大或太小
该页面受到了“最大倍数”的限制。想放大更多就调高数值，想放大少一些就调低。
左右仍然有空白
正文区域比页面更窄更长。把“左右留白”设为 0，页面宽度就会贴合内容。
全彩页面旁边出现了白边
统一页面尺寸时，比例不同的页面会留下空白。如果介意，可以关闭“所有页面统一尺寸”。
处理结果显示 ✕，没有保存
如果同名的 _TrimPDF.pdf 正在 PDF 阅读器中打开，就无法覆盖。关闭阅读器后重新放入文件。如果显示“该 PDF 设有密码，无法处理”，需要先解除密码。
显示“已跳过（不是 PDF）”
只处理扩展名为 .pdf 的文件，直接拖入整个文件夹时也会这样显示。请选中 PDF 文件本身再放入。

注意事项

  • 原文件完全不会被修改。
  • 处理前点击进度条右侧的“预览…”，可逐页查看哪些部分会被裁掉：红框内保留，暗色部分裁掉。满意后点击“按此设置处理”。
  • 处理时同一位置会变成“取消”。取消后该文件不会生成结果，等待中的文件也不再处理。处理中关闭窗口会等当前文件完成后再关闭，再次点击关闭可立即退出。
  • 处理完成后，点击结果列表中的文件名可直接打开，点击“打开文件夹”可查看保存位置。
  • 文字选择、搜索和书签（目录）会保留在结果文件中。
  • 原文件中的链接、批注和表单字段不会复制到结果文件。
  • 界面语言可在右上角的 한국어、English、中文、日本語 之间切换，所选语言保存在 %APPDATA%\TrimPDF，下次启动时保持不变。
  • 处理速度因电脑而异，300 页左右的扫描书大约需要 15 秒。
  • 结果文件大小与原文件相近。扫描图片不会重新压缩，画质不会下降。
  • 旋转的页面和横向页面也会保持原有方向。
  • 启动时，为了检查是否有新版本，只会向服务器 chaekgalpi.co.kr 发送工具名称和版本，不会发送任何文件。每天最多检查一次，取消右上角的“检查新版本”即可关闭。有新版本时，窗口底部会出现一行提示，点击“更新”会打开工具页面。程序不会自动下载或替换自身。

工作原理

给好奇的人一个简短说明。

  1. 渲染页面，寻找内容区域逐页测量纸张底色的亮度，以约 1 mm 的小格为单位，找出明显比底色暗的部分。零散的灰尘斑点和贴着边缘的细长扫描阴影会被忽略。
  2. 确定结果页面尺寸根据最大倍数和左右留白比例计算尺寸；开启统一尺寸时，所有页面都调整为代表尺寸（中位数）。
  3. 把内容放到新页面只把内容区域按原比例居中放到新页面。PDF 内容直接复制而不是转成图片，所以文字依旧清晰。

TrimPDF 使用説明書

PDF をウィンドウにドロップすると、TrimPDF がページごとに上下左右の余白を見つけてトリミングし、内容をページいっぱいに拡大して新しいファイルに保存します。スキャンした本や余白の広い文書を、タブレットや電子書籍リーダーで読みやすい大きさにしたいときに使えます。

元のファイルはそのまま結果は同じフォルダーに _TrimPDF を付けた新しいファイルとして保存します。同じ名前のファイルがすでにあれば上書きせず、(2) のように番号を付けます。
文字はくっきりページを画像にしないので、テキストの選択・検索としおりはそのまま使えます。
処理は PC の中だけファイルをアップロードすることはなく、ページ数の上限もありません。

はじめに

インストールは要りません。TrimPDF.exe は単体のファイルで、Python などがなくても Windows 10・11 で動きます。

最新の TrimPDF.exe は GitHub のリリースページからダウンロードできます。

  1. exe を好きなフォルダーに置くデスクトップやドキュメントでかまいません。よく使うなら、デスクトップにショートカットを作っておくと手早く開けます。
  2. ダブルクリックで起動する起動のたびに、準備のため数秒かかります。
  3. PDF をウィンドウにドロップする終わると「処理結果」に ✓ ファイル名_TrimPDF.pdf が表示されます。
「Windows によって PC が保護されました」と表示されたら
コード署名証明書のない個人制作のソフトなので、初めて起動したときに表示されることがあります。詳細情報を押してから実行を押してください。ウイルス対策ソフトが確認のためにしばらく止めることもあります。

ファイルの追加

次の 3 つのどれを使ってもかまいません。複数のファイルを一度にドロップすると、順番に処理します。

ウィンドウにドロップウィンドウ上部の点線の枠に PDF をドロップします。ふだんはこの方法です。
exe のアイコンにドロップTrimPDF を閉じた状態で、TrimPDF.exe かそのショートカットに PDF をドロップします。ウィンドウが開いてすぐに処理を始めます。
クリックして選ぶ点線の枠をクリックすると、ファイルを選ぶ画面が開きます。

結果は元のファイルと同じフォルダーに保存します。

会議メモ.pdf→会議メモ_TrimPDF.pdf
オプションは、ファイルを追加した時点の値で処理します。設定を変えたら、ファイルをもう一度追加してください。同じ名前の _TrimPDF.pdf がすでにある場合は上書きせず、_TrimPDF(2).pdf のように番号を付けて保存します。

  • 2

オプションの詳細

標準の設定で、たいていの文書はうまくいきます。結果が気になるときは、関係するオプションだけを変えてください。pt はポイントで、約 0.35 mm です。アプリでは項目名にマウスを合わせると短い説明が出ます。

オプション標準はたらき変えるとき
処理方法
トリミングして拡大選択余白をトリミングしてから、内容をページに合わせて拡大します。文字の縦横比は変わりません。ほとんどの文書はこれで十分です。
トリミングのみ（サイズはそのまま）—拡大せずに余白だけを取り除きます。ページは内容の大きさまで小さくなります。印刷するときや、ほかの文書に貼り付けるときなど、元の文字の大きさが必要な場合。
トリミング
残す余白5 pt見つけた内容のまわりに、この幅の余白を残します。5 pt は約 1.8 mm です。文字が端に近すぎて窮屈なとき。10 くらいに上げます。
白のしきい値2350（黒）〜255（白）のうち、この値より暗い部分を内容とみなします。スキャンでは紙の色に合わせて自動で厳しくします。汚れや色の付いた背景のせいで余白が残るとき。200 くらいに下げます。
拡大（「トリミングして拡大」のときだけ）
左右の空白50 %内容が縦長だと、左右に空白ができます。その空白のうちこの割合だけが残るように、ページの幅を縮めます。0 で左右の空白をなくし、100 で元のページ幅のままにします。
最大倍率1.5 倍小さな絵や数行しかないページが大きくなりすぎないように、拡大を制限します。もっと大きくしたいときは 2.0 に、制限しないときは 0 にします。
全ページのサイズをそろえるオンすべてのページを同じ大きさにそろえます。縦長と横長のページは別々にそろえます。ページごとに内容ぴったりの大きさにしたいとき。オフにします。
表示
言語Windows の言語右上のリストで 한국어・English・中文・日本語 を選びます。初めて起動したときは Windows の表示言語に合わせます。ほかの言語で使いたいとき。

困ったとき

余白が残るページがある
スキャンの汚れや影、薄い背景色を内容と判断しています。「白のしきい値」を 200 くらいに下げて、もう一度処理してください。
薄い文字やページ番号が端に近すぎる
「残す余白」を 10 pt 以上にしてください。
絵だけのページが大きすぎる・小さすぎる
そのページには「最大倍率」がかかっています。値を上げるともっと大きく、下げると控えめになります。
まだ左右に空白がある
文字の範囲がページより縦長です。「左右の空白」を 0 にすると、ページの幅を内容に合わせます。
全面カラーのページの横に白い帯ができる
そのページだけ、形が共通のサイズと違います。気になる場合は「全ページのサイズをそろえる」をオフにしてください。
処理結果に ✕ が出て保存されない
「結果を保存できませんでした」は、元の PDF と同じフォルダーに書き込めないときに出ます。読み取り専用の場所などです。PDF を書き込めるフォルダーにコピーしてから追加してください。「パスワードで保護された PDF のため処理できません」と出た場合は、先にパスワードを外してください。
「PDF ではないためスキップ」と出る
末尾が .pdf のファイルだけを処理します。フォルダーごとドロップしたときもこう表示されます。PDF ファイルそのものを選んでください。

知っておきたいこと

  • 元のファイルは変更しません。
  • 処理する前に、進行状況バーの右にある「プレビュー…」を押すと、ページごとにどこがトリミングされるかを確かめられます。赤い枠の中が残り、暗くなった部分が切り取られます。よければ「この設定で処理」を押してください。
  • 処理中は同じ場所が「キャンセル」に変わります。キャンセルすると、そのファイルの結果は作らず、待っているファイルも処理しません。処理中にウィンドウを閉じると今のファイルを終えてから閉じ、もう一度閉じるとすぐに終了します。
  • 処理が終わったら、処理結果のファイル名を押すと結果が開き、「フォルダーを開く」で保存した場所を表示します。
  • テキストの選択・検索としおりは、結果のファイルにも残ります。
  • 元の PDF のリンク・注釈・入力フォームは、結果にはコピーされません。
  • 画面の言語は右上のリストで 한국어・English・中文・日本語 から選べます。選んだ言語は %APPDATA%\TrimPDF に保存され、次に起動したときも同じになります。
  • 処理速度は PC によって違いますが、300 ページ前後のスキャン本で 15 秒ほどです。
  • 結果のファイルサイズは元とほぼ同じです。スキャン画像を再圧縮しないので、画質は落ちません。
  • 回転したページや横長のページも、向きを保ったまま処理します。
  • 起動時に新しいバージョンがあるかを確かめるため、ツール名とバージョンだけを Chaekgalpi のサーバー（chaekgalpi.co.kr）に送ります。ファイルは送らず、確認は 1 日 1 回までで、右上の「更新を確認」のチェックを外すと止められます。新しいバージョンがあるとウィンドウの下に 1 行の案内が出て、「アップデート」を押すとツールのページが開きます。TrimPDF が自分で更新をダウンロードしたり入れ替えたりすることはありません。
  • 不具合や使いにくい点は、右上の「ご意見を送る」から知らせてください。ブラウザーで意見を送るページが開きます。

しくみ

気になる方のための短い説明です。

  1. ページを描いて内容を探す紙の明るさを測り、それより明らかに暗い部分を約 1 mm の升目ごとに探します。散らばったほこりや、端に沿った細い影は無視します。
  2. 結果のページの大きさを決める拡大の上限と「左右の空白」の設定から決めます。「全ページのサイズをそろえる」がオンなら、すべてのページを代表的な大きさ（中央値）にそろえます。
  3. 内容を新しいページに置く内容の範囲だけを、元の縦横比のまま中央に置きます。PDF の中身を画像にせずそのまま写すので、文字はくっきりしたままです。
