TrimPDF.exe · Windows

TrimPDF 사용 설명서

PDF를 창에 끌어다 놓으면 페이지마다 위·아래·왼쪽·오른쪽 여백을 찾아 잘라내고, 내용을 페이지에 맞게 키워서 새 파일로 저장합니다. 스캔한 책이나 여백이 넓은 문서를 태블릿·이북리더에서 크게 볼 때 유용합니다.

원본은 그대로결과는 같은 폴더에 _TrimPDF를 붙인 새 파일로 저장됩니다.
글자는 선명하게이미지로 바꾸지 않아 텍스트 선택·검색과 목차가 유지됩니다.
내 PC에서만 처리인터넷에 파일을 올리지 않고, 쪽수 제한도 없습니다.

시작하기

설치 과정은 없습니다. TrimPDF.exe 파일 하나만 있으면 Windows 10·11에서 바로 실행됩니다. Python 같은 다른 프로그램도 필요 없습니다.

  1. 원하는 폴더에 exe를 둡니다바탕화면이나 문서 폴더 어디든 괜찮습니다. 자주 쓴다면 바탕화면에 바로 가기를 만들어 두세요.
  2. 더블클릭해서 실행합니다실행할 때마다 준비하느라 창이 뜨기까지 몇 초 걸립니다.
  3. PDF를 창에 끌어다 놓습니다처리가 끝나면 아래 「처리 결과」에 ✓ 파일명_TrimPDF.pdf가 표시됩니다.
“Windows의 PC 보호” 창이 뜨면
인증서로 서명되지 않은 개인 제작 프로그램이라 처음 실행할 때 나타날 수 있습니다. 추가 정보를 누른 뒤 실행을 누르세요. 백신이 검사를 위해 잠시 막는 경우도 있습니다.

파일 넣기

세 가지 방법 중 편한 것을 쓰세요. 여러 파일을 한꺼번에 넣으면 차례대로 처리합니다.

창에 끌어다 놓기프로그램 창 위쪽의 점선 상자에 PDF를 놓습니다. 가장 기본적인 방법입니다.
exe 아이콘에 놓기프로그램을 켜지 않은 상태에서 TrimPDF.exe나 바로 가기 아이콘 위에 PDF를 놓으면, 창이 열리면서 곧바로 처리합니다.
클릭해서 고르기점선 상자를 클릭하면 파일 선택 창이 열립니다.

결과는 원본과 같은 폴더에 저장됩니다.

회의자료.pdf→회의자료_TrimPDF.pdf
옵션은 파일을 넣는 순간의 값으로 적용됩니다. 설정을 바꿨다면 파일을 다시 넣어야 반영됩니다. 같은 이름의 _TrimPDF.pdf가 이미 있으면 새 결과로 덮어씁니다.

화면 구성

  • 1
    언어 선택오른쪽 위에서 한국어 · English · 中文 중에 고릅니다.
  • 2
    파일 놓는 상자PDF를 끌어다 놓거나 클릭해서 고릅니다.
  • 3
    처리 방식「여백 자르고 크게 키우기」가 기본입니다. 「여백만 자르기」는 크기를 키우지 않습니다.
  • 4
    자르기「남길 여백」과 「흰색 기준」으로 얼마나 바짝 자를지 정합니다.
  • 5
    확대좌우 빈 공간, 최대 배율, 페이지 크기 통일을 정합니다. 「여백만 자르기」를 고르면 흐리게 꺼집니다.
  • 6
    진행 막대와 처리 결과✓ 완료, ✕ 실패, – 건너뜀으로 표시됩니다.

옵션 자세히

기본값만으로도 대부분의 문서가 잘 처리됩니다. 결과가 마음에 들지 않을 때 해당 옵션만 조금씩 바꿔 보세요. 단위 pt는 1pt = 약 0.35mm입니다. 프로그램에서도 옵션 이름에 마우스를 올리면 설명이 나옵니다.

옵션기본값하는 일이럴 때 바꾸세요
처리 방식
여백 자르고 크게 키우기선택됨 여백을 자른 뒤 내용을 페이지에 맞게 키웁니다. 글자 비율은 유지합니다. 대부분 이 방식을 쓰면 됩니다.
여백만 자르기— 키우지 않고 여백만 없앱니다. 페이지가 내용 크기만큼 작아집니다. 인쇄용이나 다른 문서에 붙여 넣을 때처럼 원래 글자 크기가 필요할 때.
자르기
남길 여백5 pt 찾은 내용 둘레에 이만큼 여유를 두고 자릅니다. 5pt는 약 1.8mm입니다. 글자가 가장자리에 너무 붙어 답답하면 10 정도로 올립니다.
흰색 기준235 0(검정)~255(흰색) 가운데 이 값보다 어두운 부분을 내용으로 봅니다. 스캔본은 종이 배경 밝기에 맞춰 자동으로 더 엄격하게 적용됩니다. 스캔 얼룩이나 옅은 배경색 때문에 여백이 덜 잘리면 200 정도로 낮춥니다.
확대 (「여백 자르고 크게 키우기」에서만 적용)
좌우 빈 공간50 % 내용이 세로로 길면 좌우에 빈 공간이 생깁니다. 페이지 폭을 줄여 그 공간을 이 비율만큼만 남깁니다. 좌우 여백을 없애려면 0, 원래 페이지 폭을 유지하려면 100.
최대 배율1.5 × 작은 그림이나 몇 줄뿐인 페이지가 지나치게 커지지 않도록 확대를 제한합니다. 더 크게 보고 싶으면 2.0으로 올리고, 제한을 없애려면 0.
모든 페이지 크기 통일켜짐 모든 페이지를 같은 크기로 맞춥니다. 세로형과 가로형 페이지는 각각 따로 맞춥니다. 페이지마다 내용에 딱 맞는 크기를 원하면 끕니다.

이럴 땐 이렇게

일부 페이지에 여백이 그대로 남아 있어요
스캔할 때 생긴 얼룩, 그림자, 옅은 배경색을 내용으로 본 경우입니다. 「흰색 기준」을 200 정도로 낮춰 다시 처리해 보세요.
옅은 글씨나 쪽번호가 가장자리에 너무 붙어요
「남길 여백」을 10pt 이상으로 올리세요.
그림 한 장뿐인 페이지가 너무 크거나 작아요
「최대 배율」이 적용된 페이지입니다. 더 키우려면 값을 올리고, 덜 키우려면 낮추세요.
좌우에 여백이 아직 있어요
글 영역이 페이지보다 세로로 길어서 생긴 공간입니다. 「좌우 빈 공간」을 0으로 두면 페이지 폭이 내용에 맞춰집니다.
전면 컬러 페이지 옆에 흰 띠가 생겼어요
모든 페이지를 같은 크기로 맞추면서 비율이 다른 페이지에 남는 공간입니다. 신경 쓰이면 「모든 페이지 크기 통일」을 끄세요.
처리 결과에 ✕ 표시가 뜨고 저장이 안 돼요
같은 이름의 _TrimPDF.pdf가 PDF 뷰어에 열려 있으면 덮어쓸 수 없습니다. 뷰어를 닫고 다시 넣으세요. 「암호가 걸린 PDF라서 처리할 수 없습니다」가 뜨면 암호를 해제한 파일로 처리해야 합니다.
「PDF가 아니라서 건너뜀」이라고 나와요
확장자가 .pdf인 파일만 처리합니다. 폴더를 통째로 놓은 경우에도 이렇게 표시됩니다. 파일을 골라서 넣으세요.

알아둘 점

  • 화면 언어는 오른쪽 위에서 한국어 · English · 中文 중에 고를 수 있고, 고른 언어는 다음 실행에도 유지됩니다.
  • 원본 파일은 전혀 바뀌지 않습니다.
  • 텍스트 선택·검색, 목차(책갈피)는 결과 파일에도 그대로 남습니다.
  • 원본의 링크, 메모·주석, 입력 양식은 결과 파일에 옮겨지지 않습니다.
  • 처리 속도는 PC에 따라 다르지만, 300쪽 안팎의 스캔 책 한 권이 10초 정도 걸립니다.
  • 결과 파일 크기는 원본과 비슷합니다. 스캔 이미지를 다시 압축하지 않아 화질이 떨어지지 않습니다.
  • 회전된 페이지와 가로형 페이지도 방향을 유지한 채 처리합니다.

동작 원리

궁금한 분을 위한 짧은 설명입니다.

  1. 페이지를 그려서 내용 영역을 찾습니다페이지마다 종이 배경의 밝기를 재고, 배경보다 확실히 어두운 부분을 약 1mm 크기의 칸 단위로 찾습니다. 흩어진 먼지 같은 점과 가장자리에 붙은 얇은 스캔 그림자는 무시합니다.
  2. 결과 페이지 크기를 정합니다확대 배율 한도와 좌우 빈 공간 비율을 반영해 크기를 계산하고, 크기 통일이 켜져 있으면 전체 페이지의 대표 크기(중앙값)로 맞춥니다.
  3. 원본 페이지를 잘라 새 페이지에 배치합니다내용 영역만 새 페이지 가운데에 비율을 유지해 놓습니다. 원본을 이미지로 바꾸지 않고 PDF 내용을 그대로 옮기므로 글자가 선명합니다.
